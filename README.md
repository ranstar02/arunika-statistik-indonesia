ARUNIKA — Statistik Indonesia dalam angka: penduduk, ekonomi, kesejahteraan, dan 15 provinsi terpadat, dari data resmi BPS 2024. Situs statis tanpa build step dan tanpa network request: grafik SVG buatan sendiri, toggle tahun, tab metrik, tabel provinsi yang bisa dicari, diurutkan, dan dibandingkan, plus unduh CSV.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080. Untuk membangun dossier make.fun: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
